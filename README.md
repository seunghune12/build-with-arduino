Arduino Starter Kit Study

Arduino Starter Kit를 이용해 Arduino의 기초부터 단계적으로 학습하는 저장소입니다.

목표

* Arduino 기본 구조 이해
* 기본 전자회로 구성
* 디지털 입력/출력 사용
* 아날로그 입력과 PWM 이해
* 센서 및 액추에이터 사용
* 추후 제어 프로젝트 제작

사용 환경

* Arduino Uno
* Arduino Starter Kit
* Arduino IDE

학습 내용

현재는 Arduino Starter Kit를 이용해 기초 실습부터 진행합니다.

01. Arduino 및 IDE 설정
02. LED Blink
03. Button Input
04. Analog Input
05. PWM
06. Sensor
07. Motor / Buzzer
08. Display
09. Control
10. Final Project

세부 실습 내용과 코드는 학습 진행에 따라 순차적으로 추가할 예정입니다.
